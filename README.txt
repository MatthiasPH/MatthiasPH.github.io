HOW TO PUBLISH TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open https://github.com/MatthiasPH/MatthiasPH.github.io
3. Upload the contents of the extracted folder to the repository ROOT (do not upload the enclosing folder).
4. Replace the existing index.html / styles.css / script.js files, and add projects.html, about.html, experience.html and assets/.
5. Commit your changes, wait briefly for GitHub Pages to deploy, then hard-refresh https://matthiasph.github.io/ (Ctrl+Shift+R on Windows).

To preview locally, open index.html. For the project fade effect open projects.html and scroll through its projects section; the "Preview the crossfade" button demonstrates the transition.
